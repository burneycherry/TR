# 変圧器 機器選定 PWA

変圧器の **電源相（三相/単相/スコット 高圧-低圧・低圧-低圧）・種別（油入/モールド）・容量・一次/二次電圧（候補 or 手入力）・%Z（任意）** を入力すると、以下を即時に算出・選定する PWA です。
iOS Safari / ホーム画面追加（PWA）を主対象とし、Android Chrome でも動作します。オフライン対応。

| 項目 | 内容 |
|---|---|
| 一次電流・二次電流 | 三相 `kVA×1000/(√3×V)`、単相 `kVA×1000/V` |
| 二次側短絡電流 | `I₂×100/%Z`（%Z未入力時は容量別の標準値、一次側短絡電流[kA]入力時は電源側%Zを加算） |
| LBS 限流ヒューズ | 三菱 表5(1)（単独）/表5(2)（三相＋単相一括）、富士 JCシリーズ 油入・モールド別 標準選定表（カタログ転記） |
| 一次側ブレーカー | 低圧/低圧変圧器のみ。`定格 ≥ I₁×1.25`、一次側短絡電流入力時は Icu も確認 |
| EB（B種接地線） | 内線規程 表2.13.1：一相分容量と電圧級から接地線太さ（高圧/低圧のみ） |
| 二次側 CT | `CT一次 ≥ I₂×1.25` の最小標準値 / 5A（スコットは各座） |
| 二次側 THR | 富士電機 TU-0、整定値 `I₂×5/CT一次` を0.1A単位で切り捨て |
| 二次側分岐ブレーカー | フレーム別に `Icu ≥ 短絡電流` の最下位グレード（二次定格電流を流せるフレームまで表示） |
| 主幹ブレーカー（選択式・既定は不要） | `定格 ≥ I₂` かつ `Icu ≥ 短絡電流` の最小フレーム・最下位グレード |
| 電線・銅バー | 主幹ありはその定格以上、なしは二次定格電流以上で、社内電線規準（キュービクル 60℃/75℃）と社内銅バー規準から選定 |

## 選定データの出典

すべて `js/data.js` に集約しています（出典を確認したテーブルは `verified: true`）。

| 項目 | 出典 |
|---|---|
| LBSヒューズ | 三菱 高圧限流ヒューズ 表5(1)/5(2)、富士 JC・JBシリーズ 標準選定表 |
| ブレーカー | 三菱 WS-Vシリーズ カタログ Y-0701（25A版）、富士 オートブレーカ・漏電遮断器 総合カタログ 62D2-J-0030f（2023年1月）3章・4章 |
| %Z 標準値 | 富士油入形トップランナー変圧器（総合カタログ 62D2-J-0030f 4.4） |
| THR | 富士電機 TU-0（整定値は切り捨て） |
| EB | 内線規程 表2.13.1 |
| 電線・銅バー | 社内 電線規準（キュービクル）・銅バー規準 |

## 使い方

1. GitHub Pages で公開した URL を iPhone の Safari で開く
2. 共有ボタン →「ホーム画面に追加」で PWA としてインストール
3. 入力値は端末内（localStorage）に保存され、次回起動時に復元。「結果をコピー」でテキスト出力

## 構成

```
index.html             画面
css/style.css          スタイル（CSSカスタムプロパティ不使用）
js/data.js             選定テーブル（出典転記・ここだけ編集すれば選定が変わる）
js/calc.js             計算ロジック（DOM非依存、Node でテスト可）
js/app.js              UI
sw.js                  Service Worker（ネットワーク優先＋キャッシュ）
manifest.webmanifest   PWA マニフェスト
icons/                 アイコン
tests/calc.test.js     単体テスト
```

## 開発

ビルド不要の素の HTML/CSS/JS です。

```sh
npm run check   # 構文チェック（SyntaxError 検出）
npm test        # 計算ロジックの単体テスト
python3 -m http.server 8000   # ローカル確認 http://localhost:8000/
```

## 動作確認（GitHub Pages）

Settings → Pages → Source: *Deploy from a branch* → 作業ブランチ / `(root)` を選択。
`.nojekyll` 配置済み。全パスは相対指定なので `https://<user>.github.io/<repo>/` 配下で動作します。
更新が反映されない場合は、ページを再読み込み（SW はネットワーク優先のため通常は即反映）。
