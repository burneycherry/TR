# 変圧器 機器選定 PWA

変圧器の仕様を入力すると、一次/二次電流から LBS ヒューズ・CT・THR・分岐/主幹ブレーカー・電線/銅バー・EB までを即時に選定する PWA です。
iOS Safari / ホーム画面追加（PWA）を主対象とし、Android Chrome でも動作します。オフライン対応。

## 入力

| 項目 | 内容 |
|---|---|
| 電源相 | 三相 / 単相 / スコット（高圧/低圧）/ スコット（低圧/低圧） |
| 変圧器種別 | 油入 / モールド（富士ヒューズ選定表の切替） |
| 容量 | 標準容量から選択または手入力（単相 10〜500＋JIS外 750・1000、三相 20〜2000、スコット 10〜200 kVA） |
| 一次・二次電圧 | 候補から選択または手入力 |
| %Z（任意） | 空欄は富士油入トップランナー変圧器の標準値 |
| 一次側短絡電流（任意） | 空欄は無限大母線 |
| 二次主幹ブレーカー | 不要（既定）/ 必要 |
| LBS 共用単相変圧器（任意） | 三相高圧のとき、同じ LBS で開閉する単相変圧器の容量（一括選定） |

## 出力と選定方法

| 項目 | 選定方法 |
|---|---|
| 一次・二次電流 | 三相 `kVA×1000/(√3×V)`、単相 `kVA×1000/V`。スコットは各座 kVA/2 |
| 二次側短絡電流 | `I₂×100/(%Z変圧器＋%Z電源)` |
| LBS 限流ヒューズ（高圧） | 三菱 表5(1)（単独）・表5(2)（三相＋単相一括）、富士 JC 標準選定表（油入/モールド別） |
| 一次側ブレーカー（低圧/低圧） | `定格 ≥ I₁×1.25`。一次側短絡電流入力時は遮断容量も確認 |
| 二次側 CT | `CT一次 ≥ I₂×1.25` の最小標準値 / 5A（三菱 CWシリーズの定格一次電流、形名例も表示） |
| 二次側 THR | 富士 TU-0。整定 `I₂×5/CT一次` を 0.1A 単位で**切り捨て**（過負荷前に警報を出すため） |
| 母線 電線 | 社内規準 許容電流表 IV・FP 60℃・HIV・EM-IE・EM-LMFC 75℃ を併記、最小 5.5sq、2条引きまで（1本 ≥ 電流×60%）。超える場合は銅バーのみ |
| 母線 銅バー | 社内規準（10t×50 880A 〜 15t×150×2 4045A） |
| EB（B種接地線） | 内線規程 表2.13.1（一相分容量・電圧級）。分岐（主幹）ブレーカーのサイズによるサイズアップ（表2.13.2）を併記 |
| 二次主幹ブレーカー（必要時） | `定格 ≥ I₂` かつ `Icu ≥ 短絡電流`。MCCB と ACB を別々に選定（800A以上は ACB も表示） |
| 二次側分岐ブレーカー | フレーム別に `Icu ≥ 短絡電流` の最下位グレード。二次定格電流を流せるフレームまで表示 |

例：単相100kVA・6600/210V → 二次476.2A、CT 600/5A、THR TU-0 整定 3.9A。単相20kVA → 95.2A、CT 120/5A。

## 選定データの出典

すべて `js/data.js` に集約（出典確認済みのテーブルは `verified: true`）。

| 項目 | 出典 |
|---|---|
| LBSヒューズ | 三菱 高圧限流ヒューズカタログ K-K06-6-C1034 表5(1)/5(2)、富士 JC・JBシリーズ 標準選定表 |
| 配線用遮断器 | 三菱 WS-Vシリーズ Y-0701（25A版）、富士 オートブレーカ・漏電遮断器 総合カタログ 62D2-J-0030f（2023年1月） |
| 気中遮断器 | 三菱 AE-SW（Y-0701）、富士 DHシリーズ 62D1-J-0191c |
| %Z 標準値 | 富士 総合カタログ 62D2-J-0030f 4.4（油入トップランナー変圧器） |
| CT | 三菱 計器用変成器 Y-0550 CWシリーズ |
| THR | 富士電機 TU-0 |
| EB | 内線規程 表2.13.1・表2.13.2 |
| 電線・銅バー | 社内 電線規準（キュービクル）・銅バー規準、JSIA 並列配線（60%） |
| 標準容量 | 日立産機システム 変圧器ラインアップ |

短絡電流は %Z のみの簡易計算です。電圧降下・布設条件の低減は別途検討してください。

## 使い方

1. GitHub Pages の URL を iPhone の Safari で開く
2. 共有ボタン →「ホーム画面に追加」で PWA としてインストール
3. 入力値は端末内に保存され次回復元。「結果をコピー」でテキスト出力

## 構成

```
index.html             画面（注意事項の文言を含む）
css/style.css          スタイル（CSSカスタムプロパティ不使用）
js/data.js             選定テーブル（出典転記・ここだけ編集すれば選定が変わる）
js/calc.js             計算ロジック（DOM非依存、Node でテスト可）
js/app.js              UI
sw.js                  Service Worker（ネットワーク優先＋キャッシュ）
manifest.webmanifest   PWA マニフェスト
icons/                 アイコン
tests/calc.test.js     単体テスト
CLAUDE.md              開発ルール・仕様の詳細（Claude Code 用）
```

## 開発

ビルド不要の素の HTML/CSS/JS です。

```sh
npm run check                 # 構文チェック（SyntaxError 検出）
npm test                      # 計算ロジックの単体テスト
python3 -m http.server 8000   # ローカル確認 http://localhost:8000/
```

## 動作確認（GitHub Pages）

Settings → Pages → Source: *Deploy from a branch* → 作業ブランチ / `(root)`。
`.nojekyll` 配置済み。パスは相対指定なので `https://<user>.github.io/<repo>/` 配下で動作します。
