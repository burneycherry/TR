注意事項

  • ブレーカーは三菱 WS-V（Y-0701 25A版）・富士 G-TWIN（総合カタログ 62D2-J-0030f 2023年1月）・ACB DHシリーズ（62D1-J-0191c）の値から選定しています。主幹が800A以上の場合は ACB も示します。分岐ブレーカーはフレームごとに、必要遮断容量（JIS C 4620 等の表または計算値）以上の Icu を持つ最下位グレードを示します。三菱 63AF は 50A までとしています。
  • 低圧/低圧変圧器の一次側ブレーカーは、三菱 Y-0701 表4-25「変圧器一次側用遮断器の選定」（励磁突入電流例①〜③）と富士 総合カタログ 4.11「変圧器一次側回路の選定」（一次側短絡電流×容量）によります。スコットは専用表が無いため三相表を準用します。励磁突入電流は変圧器メーカーに確認してください。
  • 容量の候補は日立産機システムの標準容量です。JIS C 4304（油入）・C 4306（モールド）表3 の定格容量（単相10〜500・三相20〜2000kVA）にないもの（単相750/1000kVA）は「JIS外」と表示します。候補にない容量は「手入力」を選んでください。
  • タップ電圧（6kV の単相・三相・日立灯動、「表示する」で表示）は JIS 表4 の値で、受電電圧に対する各タップの無負荷二次電圧（受電電圧×定格二次電圧÷タップ電圧）を比較します。選定計算は定格電圧（R6600V）基準です。
  • %Z 未入力時は日立 SuperトップランナーⅢ（カタログ ST-156）特性表の短絡インピーダンス（油入/モールド・50/60Hz・単相/三相210V/三相420・440V 別、代表値）を使用します。表にない容量は直近下位の容量の値です。
  • キュービクル（三相6.6kV/210V・単相6.6kV/210-105V、三相30〜750kVA・単相30〜500kVA）は、ブレーカーの遮断容量を JIS C 4620:2023 解説表1（2018と同値、JIS C 4304 変圧器の短絡電流最大値）の値で選定します（各ブレーカーの定格列）。JIS に無い範囲（三相1000〜2000kVA・400V回路）はキュービクル式非常電源専用受電設備 認定の手引き（2013/6/27版）補足表1 で補完し、表の最大列超・対象外・灯動・スコットは計算値です。「計算値（%Z）」に切り替えることもできます。
  • 短絡電流は %Z のみ（R/X 分離なし）の簡易計算です。電源側は一次側短絡電流を入力した場合のみ考慮します。
  • 単相3線式の105V側短絡電流は210V側の値と異なります。
  • スコット変圧器の二次側は M座・T座 各 容量/2 の単相回路として計算し、同じ機器を2回路分選定します。B種接地（EB）は各座の中点 o1・o2 から取ります。
  • 結線図はベクトル図の角度で示しています。単相・三相（6kV/低圧）は JIS C 4304（油入）・C 4306（モールド）表18〜20 により、三相210V は 20〜50kVA Y-Y（Yy0）、75〜500kVA Y-Δ（Yd1：二次30°遅れ）、750・1000kVA Δ-Δ（Dd0、日立標準。JIS では Y-Δ も可）、1500・2000kVA Δ-Δ、420V(50Hz)/440V(60Hz) は Δ-Y 中性点端子付き（Dyn11：二次30°進み。JIS は 1500・2000kVA、75〜1000kVA は JEM 1520/1521 準拠の日立標準品）です。JIS は 6kV 配電用のため、3.3kV などは参考表示です。低圧/低圧・スコット（二次90°）・灯動はメーカーカタログの代表例です。実機は銘板・仕様書で確認してください。
  • 三相3線は結線図の欄で結線（Y-Y・Y-Δ・Δ-Δ・Δ-Y）を選べます。最初は代表例を表示し、JIS（表19・表6）にない結線を選ぶと注意を表示します。結線図の下の二次側電圧（線間・対地）は無負荷・定格電圧の値です。単相2線は一端接地、単相3線は中性点接地としています。
  • 三相4線式は線間電圧で三相と同じ計算です。灯動共用変圧器（日立 SuperトップランナーⅢ 70〜150kVA／三菱 Rシリーズ ダブルパワー 50〜500kVA）は一次・LBSヒューズを定格容量の三相変圧器として選定し、二次は負荷配分曲線上の配分（三相側か単相側の一方を入力、空欄は曲線の折れ点）で三相側・単相側をそれぞれ選定します。曲線は各社カタログのグラフからの読取値です。%Zは日立は特性表の周波数別の値、三菱は保証値範囲の下限（安全側）、短絡電流は簡易計算です。EBの一相分容量は単相分＋三相分÷3としています。
  • LBSヒューズは三菱 表5(1)/5(2)、富士 JCシリーズ標準選定表（カタログ転記）によります。表にない容量は直近上位容量の行で選定します。
  • 変圧器二次側母線（電線・銅バー）は主幹ブレーカーありの場合はその定格以上、なしの場合は二次定格電流以上で選定しています。母線の電線は社内規準の許容電流表（IV・FP 60℃・HIV・EM-IE・EM-LMFC 75℃）によります。電線は最小5.5sq、2条引きまで（JSIA：1本の許容電流は回路電流の60%以上）とし、超える場合は銅バーのみです。EBは内線規程 表2.13.1によります（分岐・主幹ブレーカーのサイズによっては表2.13.2 によりサイズアップ。目安を併記）。電圧降下・布設条件の低減は別途検討してください。
